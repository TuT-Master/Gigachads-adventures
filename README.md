Gigachad's Adventures

My first large scale project. The game where player goes through generated dungeons, collects resources and experiences. Then in base crafts new weapons and armors, upgrades the base and challenge hard bosses for even better loot.

In this state the game is not done, but you can do pretty much everything what is written above. There is only one enemy tho. The dungeons are generated, loot is collected and stored in your base, crafting and leveling up is possible too. And there are many memes too :).

I plan to continue with this game somewhere in future.
