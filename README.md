Gigachad's Adventures

My first large scale project. The game where player goes through generated dungeons, collects resources and experiences. Then in base crafts new weapons and armors, upgrades the base and challenge hard bosses for even better loot.

In this state the game is 'almost' done. You can do pretty much everything what is written above but there is only one enemy. Tho, the dungeons are generated, loot is collected and stored in your base, crafting and leveling up is possible too.
I plan to continue with this game somewhen in future.
